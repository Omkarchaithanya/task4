# SQL Joins – Task 4

## Internship Task
SQL Intermediate – Joins (INNER, LEFT) + Business Questions

## Dataset
Chinook Database

## Database Used
MySQL

## Description
This task demonstrates the use of SQL JOIN operations (INNER JOIN and LEFT JOIN) to combine multiple tables and answer business-related questions.

The following were implemented:
- INNER JOIN to combine customers and orders
- LEFT JOIN to identify customers with no orders
- Revenue calculation per product
- Category-wise revenue distribution
- Business filtering using WHERE clause

## Files Included
- joins_queries.sql – All SQL queries with comments
- joined_output.csv – Exported joined result
- insights.txt – Business insights derived from the data
